# Positivity of Single-Centred Black Hole Indices in the Z2 CHL Model

Paper and verification code by Deep Bhattacharjee.

- `paper/` — LaTeX source (`main.tex`, `parts/`), figures and PDF; `TexmdpiCHLPositivity.zip` is the TeX package.
- `code/chl_coefficients.py` — exact orbit computation (python-flint); `code/verify_table.py` — the table of values.
- `code/certificate/` — ball-arithmetic certificates (`pmin.py`, `gmono2.py`, `cert.py`, `analytic.py`, `analytic2.py`, `polar.py`) and their outputs.

Proved: positivity for Q² ≤ 2 and for every charge of discriminant at most 800. All charges: proved under the stated Rademacher hypothesis R.
